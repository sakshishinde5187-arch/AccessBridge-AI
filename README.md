# AccessBridge AI

AI-powered document assistant for accessible document understanding.

## 📌 About the Project

AccessBridge AI helps users understand difficult documents such as certificates, notices, letters, and other important documents.

The user can upload a PDF or image, select Marathi or English, and get an easy-to-understand analysis of the document.

## ✨ Features

- 📄 PDF document upload
- 🖼️ Image document upload
- 🤖 AI-powered document analysis
- 🌐 Marathi and English support
- 📅 Important dates and deadlines extraction
- 💰 Important amounts and financial information extraction
- 📋 Required actions and documents
- 💡 Simple explanation of complex documents
- 🔊 Text-to-speech in Marathi and English
- 🔒 API key protected using environment variables
- 📱 Mobile-friendly interface

## 🔄 How It Works

1. Upload a PDF or image.
2. Select the preferred language.
3. AccessBridge AI extracts the document content.
4. Gemini AI analyzes the document.
5. The system identifies:
   - Document type
   - Important information
   - Dates and deadlines
   - Amounts
   - Required actions
   - Simple explanation
6. Users can listen to the explanation using text-to-speech.

## 🎯 Problem We Address

Many important documents contain complex language, technical terms, dates, amounts, and instructions that can be difficult for users to understand.

AccessBridge AI converts complex document information into simple, actionable information in the user's preferred language.

## 🌍 Impact

AccessBridge AI aims to make important documents easier to understand and more accessible, especially for users who may struggle with complex official or administrative language.
